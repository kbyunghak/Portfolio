# Portfolio Documentation Standards

Shared standards for Andrew Kim's personal software projects.

## Standards

- [README Standard](README_STANDARD.md) — required README section order, badge
  policy, project types, and project-specific flow patterns.
- [Commit Standard](COMMIT_STANDARD.md) — shared commit-message format, allowed
  types, commit-scope rules, and pre-commit checks.

These documents are the source of truth for shared repository conventions.
Project-specific contributing guides may add requirements without contradicting
these standards.
